# Ganpati Invitation Website

## Files
- index.html
- style.css
- script.js
- assets/bappa.jpg
- assets/devotional-music.mp3

## Before publishing
1. Rename your Bappa photo to `bappa.jpg` and put it inside `assets`.
2. Add a devotional instrumental audio file named `devotional-music.mp3` inside `assets`.
3. Open `index.html` to preview, or publish the folder using GitHub Pages.

## GitHub Pages
1. Create a public GitHub repository named `ganpati-invitation`.
2. Upload all files and the `assets` folder.
3. Go to Settings > Pages.
4. Select Deploy from a branch, branch `main`, folder `/root`.
5. Save. Your link will look like:
   https://YOUR-USERNAME.github.io/ganpati-invitation/
